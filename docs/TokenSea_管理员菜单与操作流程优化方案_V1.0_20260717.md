# TokenSea 管理员菜单与操作流程优化方案 V1.0

> 日期：2026-07-17  
> 适用对象：TokenSea 平台管理员  
> 优化目标：减少菜单噪声，让管理员围绕“Key、调用、模型、路由、租户、成本”完成主要工作；低频技术诊断页面保留能力但不占用主菜单。

## 1. 优化原则

1. **按使用频率排序，而不是按技术模块堆叠。**
2. **高频运营入口前置，低频治理入口下沉。**
3. **自动化流程不再单独提供常驻菜单。** 例如能力探测、模型发现、同步任务已经可以由供应商渠道或路由生效流程触发。
4. **不删除后端能力和页面路由。** 从主菜单移除只代表降低入口层级，仍可从相关业务页面、工作台、错误提示或直接路由进入。
5. **管理员直达，系统校验。** 日常操作不再依赖审批中心往返，高风险价格变更等治理事项继续保留。

## 2. 管理员主要工作频次

### 高频：每天或每周多次

- 创建、生成、禁用 API Key；
- 查看调用日志和请求错误；
- 查看用量；
- 处理告警；
- 查看渠道健康。

### 中频：新供应商、新模型或配置变更时

- 配置供应商渠道；
- 查看模型部署；
- 核对模型生效价格；
- 创建或发布企业服务模型；
- 创建并生效路由策略；
- 管理租户、项目和应用。

### 低频：价格变化、对账、审计或故障诊断时

- 审核供应商价格差异；
- 配置价格源；
- 查看供应商官方价格目录；
- 查看操作审计；
- 修改系统基础设置；
- 查看原始快照、同步任务、错误码、敏感访问记录等技术明细。

## 3. 新菜单结构

### 3.1 日常运营

默认展开，放置最高频入口：

1. API Key
2. 调用日志
3. 用量分析
4. 告警事件
5. 渠道健康

### 3.2 模型配置

按真实配置依赖顺序排列：

1. 供应商渠道
2. 模型部署
3. 模型生效价格
4. 企业服务模型
5. 路由策略

说明：企业服务模型需要先建立草稿，再由路由策略关联；最终发布时由系统校验路由、能力和价格状态。

### 3.3 租户与应用

1. 租户管理
2. 项目管理
3. 应用管理

### 3.4 成本管理

1. 预算管理
2. 内部成本单
3. 供应商对账

“用量分析”属于高频运营入口，已前置到“日常运营”，不在成本菜单中重复出现。

### 3.5 高级治理

1. 价格差异审核
2. 价格源管理
3. 供应商官方价格目录
4. 操作审计
5. 系统基础设置

## 4. 从主菜单下沉的页面

以下页面不删除，只是不再常驻左侧菜单：

| 页面 | 下沉原因 | 推荐入口 |
|---|---|---|
| 供应商模板 | 新建渠道时选择即可，管理员很少单独维护 | 供应商渠道表单或直接路由 |
| 公共模型参考库 | 参考数据，不属于日常运营 | 供应商渠道/模型部署辅助入口 |
| 公共价格参考 | 参考数据，不是最终计费依据 | 模型生效价格辅助入口 |
| 能力验证 | 路由“校验并生效”已自动探测 | 模型部署详情或路由错误提示 |
| 模型数据源 | 初始配置后低频使用 | 高级诊断入口 |
| 模型同步任务 | 自动任务，不需要长期占菜单 | 供应商渠道同步结果入口 |
| 模型发现 | 渠道发现模型动作已经覆盖 | 供应商渠道操作入口 |
| 模型差异审核 | 只有模型变化时使用 | 同步结果或告警入口 |
| 价格同步任务 | 自动任务 | 价格源管理详情 |
| 价格原始快照 | 证据追溯页面 | 价格差异详情 |
| 申请审批 | 管理员低风险流程已直接生效 | 仅高风险操作跳转进入 |
| 发布记录 | 审计性质，低频 | 企业服务模型详情或操作审计 |
| 敏感查看 | 安全审计专用 | 操作审计关联入口 |
| 错误码中心 | 开发和运维诊断专用 | 错误提示中的帮助入口 |

## 5. 工作台调整

工作台快捷入口改为：

1. 管理 API Key；
2. 发布企业服务模型；
3. 校验并生效路由；
4. 排查调用链。

工作台不再把“模型差异审核”作为通用快捷操作，因为该页面只在同步发现变化时才需要进入。

渠道健康文案由“近 30 分钟连接成功”改为“连接测试仍在有效期内”，与当前 7 天可配置有效期保持一致。

## 6. 保留的治理边界

菜单简化不代表取消治理。以下场景继续保留明确校验或审批：

- 供应商官方价格变化和高风险价格发布；
- 企业服务模型主动配置为需要审批；
- 强预算阻断或重大预算策略；
- 安全敏感查看和密钥操作审计；
- DNS、供应商渠道、模型能力和价格完整性校验。

## 7. 后续建议

1. 在供应商渠道详情增加“发现记录、部署、连接测试记录”的页内 Tab，进一步替代多个独立菜单。
2. 在价格差异详情增加“原始快照、解析结果、生效版本”页内联动。
3. 在企业服务模型详情增加“路由、价格、能力、Key 使用情况”综合视图。
4. 对隐藏页面提供上下文跳转，不依赖管理员记忆 URL。
5. 根据实际访问日志继续调整菜单顺序，而不是固定不变。
